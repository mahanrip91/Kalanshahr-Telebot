# 🏙️ ربات کلان‌شهر

ربات تلگرام اقتصادی + شبیه‌سازی زندگی، ساخته‌شده با aiogram 3.x

## 🚀 نصب روی ترموکس (گوشی اندروید)

### مرحله ۱ — انتقال پوشه
این پوشه کامل (`kalanshahr_bot`) رو داخل ترموکس منتقل کن. اگه از طریق مرورگر دانلود کردی معمولاً تو
`/sdcard/Download` هست. برای دسترسی ترموکس به فایل‌های گوشی اول این دستور رو بزن:

```bash
termux-setup-storage
cp -r /sdcard/Download/kalanshahr_bot ~/kalanshahr_bot
cd ~/kalanshahr_bot
```

### مرحله ۲ — نصب خودکار
```bash
bash install.sh
```

این اسکریپت خودش پایتون، پکیج‌ها و همه‌چیز رو نصب می‌کنه و یک فایل `.env` می‌سازه.

### مرحله ۳ — تنظیم توکن
```bash
nano .env
```
مقدار `BOT_TOKEN` رو با توکنی که از @BotFather گرفتی جایگزین کن.
مقدار `OWNER_ID` رو هم با آیدی عددی خودت (از @userinfobot) جایگزین کن تا به پنل ادمین دسترسی داشته باشی.

با `Ctrl+O` سیو کن، `Enter` بزن، بعد `Ctrl+X` برای خروج.

### مرحله ۴ — اجرا
یک بار ترموکس رو ببند و دوباره باز کن (یا بزن `source ~/.bashrc`)، بعد بنویس:

```
S Kalan
```

ربات بالا میاد! 🎉

برای متوقف کردن ربات، `Ctrl+C` بزن.

## 💬 دستورات متنی (بدون نیاز به دکمه)
تقریباً همه‌ی بخش‌های ربات رو می‌تونی هم از دکمه‌های پایین صفحه، هم با تایپ کردن اسمشون صدا بزنی —
چه تو چت خصوصی، چه داخل گروه. مثلاً: «کار»، «بانک»، «کازینو»، «خلاف»، «مغازه»، «بازار»، «جوایز»،
«رتبه‌بندی»، «کلان‌شهر»، «راهنما»، «تنظیمات»، «حساب من».

## 💰 نوشتن مبلغ
هر جای ربات که باید مبلغی وارد کنی، می‌تونی بنویسی: `5000` یا `5k` یا `۵هزار` یا `۵ هزار تومان` یا
`۵ میلیون` — بات خودش تشخیص میده.

## 🎰 کازینو
بازی‌های شانسی واقعی تلگرام (تاس، دارت، بولینگ، بسکتبال، فوتبال، اسلات): مبلغ شرط رو میدی، بات
۶۰ ثانیه فرصت میده که همون ایموجی رو بفرستی و روی پیام بات ریپلای کنی. نتیجه‌ی واقعی همون چیزیه که
تلگرام برای ایموجیِ خودت نشون میده. علاوه بر اینا، سکه و رولت هم به‌صورت آنی بازی میشن.

## 🕵️ خلاف
جایگزین بخش قدیمی قاچاق. دو زیربخش داره: خلاف تکی (چند نوع کار خلاف با ریسک متفاوت) و خلاف گروهی
(سرقت بزرگ بانک که فقط داخل گروه و با تیم انجام میشه).

## 🏙️ سیستم کلان‌شهر (گروه‌ها)
- ربات رو به یه گروه اضافه کن.
- اگه گروه کمتر از حد نصاب عضو داشته باشه (پیش‌فرض ۱۰ نفر)، با پیام طعنه‌آمیز جواب میده.
- به محض رسیدن به حد نصاب، پیام تبریک میده، شهر رسماً فعال میشه، و **مالک واقعی گروه به‌طور خودکار
  اولین شهردار میشه**.
- داخل گروه بنویس «کلان‌شهر» تا وضعیت شهر رو ببینی.
- بخش‌های شهرداری (انتخابات)، خزانه (کمک مالی و ارتقای سطح شهر)، و زندان همگی داخل همین منو هستن.
- ادمین‌های واقعی گروه با نوشتن «مدیریت شهر» به پنل مدیریتی دسترسی دارن.

## 👑 دستورات مخصوص مالک ربات
- `اخراج <آیدی>` — کاربر رو از ربات اخراج می‌کنه (پیشرفتش حفظ میشه، فقط دیگه نمی‌تونه از ربات استفاده کنه)
- `رفع اخراج <آیدی>` — کاربر اخراجی رو با همون پیشرفت قبلی برمی‌گردونه
- `ری استارت` — با تایید، **کل دیتابیس رو پاک می‌کنه** و ربات رو از صفر ریستارت می‌کنه (غیرقابل بازگشت!)
- `/شارژ`, `/شارژبانک`, `/کدهدیه`, `/آمار`, `/ریست`, `/همگانی` — مثل قبل

## 🏦 بانک و شماره حساب
هر کاربر یه شماره حساب یکتا داره (از منوی بانک یا تنظیمات قابل مشاهده‌ست) و می‌تونه مستقیم با شماره
حساب برای بقیه پول منتقل کنه (بخش «انتقال به حساب» در منوی بانک، با تایید نهایی).

## ⚙️ تغییر تنظیمات اقتصاد
همه اعداد (حقوق مشاغل، نرخ سود بانک، نرخ وام، حد شرط‌بندی، قیمت املاک و...) داخل فایل
`config.py` قابل تغییرن. بعد از هر تغییر، فقط کافیه ربات رو دوباره با `S Kalan` اجرا کنی.

## 🔒 نکته امنیتی
فایل `.env` رو هیچ‌وقت جایی پابلیک آپلود نکن (مثلاً گیت‌هاب عمومی) چون توکن ربات توشه.
